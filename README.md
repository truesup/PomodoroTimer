# Pomodoro Timer

## Description

Pomodoro Timer is a learning project created for practicing React 19.

Pomodoro Timer helps manage time efficiently by dividing work into intervals (pomodoros) with short and long breaks. The interface is simple and user-friendly, inspired by [this design](https://www.figma.com/community/file/1112830528857083939/pomo-pomodoro-timer-app-prototype-v-0-1-0) from Figma.

---

## Описание

Pomodoro Timer — учебный проект, созданный для практики работы с React 19.

Pomodoro Timer помогает эффективно управлять временем, разделяя работу на интервалы (помидоры) с короткими и длинными перерывами. Интерфейс прост и удобен, вдохновлён [этим дизайном](https://www.figma.com/community/file/1112830528857083939/pomo-pomodoro-timer-app-prototype-v-0-1-0) из Figma.
